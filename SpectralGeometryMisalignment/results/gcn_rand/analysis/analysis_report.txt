EXPERIMENTAL SETUP
------------------
Goal: Isolate what graph topology contributes to classification accuracy
      when node features carry ZERO class information.

X_rand ~ N(0,1), same shape as real X, independent of labels.
Y_rand = Rayleigh-Ritz eigenvectors of (L,D) restricted to span(X_rand).
         Y_rand ≈ randomized approximation to leading Laplacian eigenvectors.
         Class-informative content of Y_rand = 0 by construction.

5 models compared:
  GCN_X         : 2-layer Kipf GCN on real X          [feature ceiling]
  GCN_rand      : 2-layer Kipf GCN on X_rand          [topology via MP]
  GCN_rowNorm_Y : 2-layer GCN on Y_rand, row-norm at each layer input
  MLP_Y         : Linear classifier on Y_rand + StandardScaler
  MLP_rowNorm_Y : Linear classifier on row-normalized Y_rand

Training: SGD(mom=0.9,wd=0) + Adam(betas=(0.9,0.999),wd=0), LR∈{0.001,0.01,0.1}
          500 epochs, no early stopping, full-batch.
Seeds: 5 train seeds × 3 X_rand draws × 6 split configs (1 fixed + 5 random)
Datasets: 9 (all LCC-extracted)

Canonical config for R2–R8: adam, lr=0.01, fixed split, split_seed=0
